1. Operating Framework

Every sprint follows a fixed delegation ladder: deterministic pre-flight checks run first at zero token cost before escalating through Chief of Staff triage, scoped domain Managers, and single-purpose Workers.

Context Isolation

Chief of Staff reads only a compact < 8 KB state snapshot, task board, and quota ledger—never scanning source files across repositories.

Bounded Fan-Out

At most 1 active area per cycle and ≤ 2 disjoint worker assignments per Manager, preventing parallel file conflicts or quota spikes.

Zero-Trust Verification & Privacy

Every change requires independent Verifier sign-off (`tsc`, lint, domain checks). Private domains remain strictly isolated and excluded from public exports.
